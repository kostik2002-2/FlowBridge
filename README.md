# FlowBridge

<img src="assets/flowbridge-512.png" width="96" alt="FlowBridge">

Бесплатный помощник совместимости Google Flow для Windows. Открытый исходный код, лицензия MIT.

**[Скачать FlowBridge-Setup.exe](https://github.com/kostik2002-2/FlowBridge/releases/latest/download/FlowBridge-Setup.exe)** · [Все релизы](https://github.com/kostik2002-2/FlowBridge/releases) · [Сообщить о проблеме](https://github.com/kostik2002-2/FlowBridge/issues)

## Установка

1. Включите VPN или обеспечьте подходящий сетевой доступ к Google Flow.
2. Скачайте и запустите `FlowBridge-Setup.exe`.
3. Выберите установленный браузер и нажмите **Установить**.
4. Дождитесь сообщения **Установлено**. Откроется новая вкладка Flow.

Браузер и вкладку Flow заранее открывать не нужно: установщик запустит браузер и подготовит новую вкладку. В списке отображаются только найденные установленные браузеры.

Для передачи программы достаточно одного EXE: расширения и иконки уже внутри.
Установщик сохраняет файлы в `%LOCALAPPDATA%\FlowBridge`. Для Chromium не удаляйте эту папку, пока используете расширение.
Папка `versions\0.1.0` сохранена для совместимости с существующими установками; версия расширения этого релиза — **0.1.1**.

| Браузер | Способ установки |
| --- | --- |
| Google Chrome, Comet, Microsoft Edge, Opera, Яндекс Браузер | Распакованное расширение; установщик включает режим разработчика |
| Mozilla Firefox 142+ | XPI с подписью Mozilla |

Системные шаги установки и подтверждения браузера могут быть видны. Размер окна сохраняется.
При подготовке новой вкладки закрываются предыдущие вкладки Flow в том же окне и очищаются cookies только точного домена `flow.google.com`.
Общие cookies `.google.com`, другие сайты и другие окна сохраняются.
Служебная вкладка установщика закрывается. Повторная установка актуальной версии выводит **Расширение уже установлено**.
Для старых версий предусмотрено обновление, когда установщик может определить их версию.

## Что делает FlowBridge

Расширение меняет отрицательный результат конкретной **клиентской проверки страны** в Google Flow.
Оно работает только на `https://flow.google.com/*`, показывает локальный статус и не загружает исполняемый код с сервера.

FlowBridge не предоставляет VPN, Google-аккаунт, подписку, кредиты или серверный доступ и не меняет возрастную проверку.
Google может изменить код сайта — тогда потребуется новая версия расширения.
Открытие интерфейса само по себе не подтверждает доступность генерации. Автоматические проверки не запускают платную генерацию.

Проект не связан с Google или Mozilla и не является их продуктом.
XPI подписан Mozilla; **Windows EXE не подписан сертификатом издателя**.

## Приватность

Телеметрии и сервера лицензирования нет. Расширение не отправляет данные разработчику.
Разрешение `tabs` используется для подготовки вкладки Flow и чтения диагностического состояния,
`cookies` — для локальной очистки cookies точного домена Flow. Значения cookies разработчику не передаются.

## Удаление

Удалите **FlowBridge Preview** через менеджер расширений каждого браузера.
Затем при необходимости удалите `%LOCALAPPDATA%\FlowBridge`.
Параметры VPN и системные политики установщик не меняет.

## Сборка из исходников

Нужны Windows, Node.js 22+ и компилятор .NET Framework 4.x с библиотеками Windows Forms / UI Automation.
Проверено с Windows 11 и Node.js 24.17.0. Дополнительные npm-пакеты не нужны.

```powershell
node tools/build.cjs
node --test
node tools/verify-icons.cjs
node tools/payload.cjs
powershell.exe -NoProfile -ExecutionPolicy Bypass -File installer/build.ps1
```

Результат: `package/FlowBridge-Setup.exe`.
Код расширения находится в `src/`, установщика — в `installer/`, тесты — в `tests/`.
Подписанный Firefox XPI 0.1.1 включён в репозиторий как входной файл сборки;
его SHA-256 проверяется при упаковке и перед установкой.

**Изменение кода Firefox требует увеличения версии и новой подписи Mozilla.**
`tools/build.cjs` создаёт неподписанные расширения; готовый подписанный XPI он не изменяет.
Сборка EXE использует именно проверенный подписанный XPI.
Нельзя выдать пересобранное изменённое расширение за уже подписанный файл.

## Установщик 0.1.3

Исправлена установка при закрытом браузере и без открытой вкладки Flow. Установщик дожидается окна с готовой адресной строкой, сохраняет выбранное окно и подтверждает открытие Flow после установки. Проверены Firefox, Chrome, Comet, Edge, Opera и Яндекс. [Подробности и сценарии проверки](docs/browser-startup.md).

## Установщик 0.1.2

Исправлено завершение установки и обновления Firefox: установщик дожидается подтверждения фактической версии расширения, определяет его текущий адрес и проверяет открытие новой вкладки Flow. Обновление с 0.1.0 до 0.1.1 проверено без предварительного удаления. Само подписанное расширение остаётся версии 0.1.1.

## Проверки и ограничения

Версия 0.1.1 поддерживает фабрики вычислений V и W после изменения кода Flow.
14 автоматических тестов проверяют точность изменения, сохранение возрастной проверки,
очистку cookies и сохранение посторонних вкладок. Механизм и интерфейс Flow проверялись локально;
генерация в рамках автоматической проверки не запускалась.

Автоматизация установки рассчитана на обычные окна браузеров с русским или английским интерфейсом.
В других профилях, при политиках организации и изменении интерфейса браузера может потребоваться ручная установка.
Публичный код Google и сторонний FlowFix в репозиторий не включены.
