# Аудит и очистка 0.1.4

Дата: 31 октября 2026 года. Проверены исходники расширения, установщик Windows, сборочные скрипты, тесты и состав публикуемого репозитория.

## Исправления

- Удалены устаревшие поля и ветки «нужна подпись»: все поддерживаемые браузеры уже имеют рабочий способ установки.
- Удалены неиспользуемая переменная, импорт и параметр выбора режима окна. Убрана повторная фильтрация найденных браузеров.
- Общая проверка принадлежности элемента интерфейсу браузера заменяет дублирующийся обход дерева. Поиск адресной строки исключает элементы внутри веб-документов.
- Привязка к окну сбрасывается в начале новой операции. Старый идентификатор окна не мешает следующей установке после перезапуска браузера.
- Сборка пересоздаёт только свои генерируемые каталоги расширений; проверено удаление тестовых устаревших файлов. Тест упаковки проверяет точный разрешённый список файлов.
- В EXE упаковываются Chromium и подписанный Firefox XPI. Неподписанная дублирующая копия Firefox больше не извлекается при установке.
- Исправлена ссылка на отсутствующий скрипт в сообщении сборки. Сборка останавливается при предупреждениях компилятора.
- Добавлены проверка точного состава встроенных файлов и интерактивный тест выбора элементов браузера и устаревшего идентификатора окна.

Рабочие файлы ранее установленных расширений автоматически не удаляются: сторонний профиль мог ссылаться на них. Каталог установки Chromium сохранён.

## Результаты проверки

- 15 Node.js-тестов прошли.
- EXE собран без ошибок и предупреждений.
- Проверка всех размеров PNG/ICO и ссылок на иконки прошла.
- SHA-256 подписанного Firefox XPI сохранился. Все 18 файлов сборки Firefox соответствуют содержимому XPI: manifest сравнивается как JSON, остальные файлы побайтово; служебные подписи META-INF исключены из сравнения исходников.
- Список интерфейса соответствует найденным установленным браузерам.
- Повторная установка проверена в Chrome, Comet, Edge, Opera, Яндекс Браузере и Firefox.
- Свежая установка при закрытом браузере повторно проверена в Chrome и Firefox.
- В Firefox повторно проверены установка без Flow, сохранение посторонних вкладок, границ окна и состояния максимизации.
- Интерактивный тест в Chrome подтвердил исключение веб-контента из элементов браузера и восстановление после устаревшей привязки к окну.

Код расширения и подписанный XPI версии 0.1.1 не изменены. Платная генерация не запускалась.

## Границы аудита

Это проверка исходников и локальные проверки, а не независимый сертификат безопасности или доказательство отсутствия всех дефектов.

Расширение имеет разрешения tabs и cookies для подготовки Flow; доступ к содержимому сайтов ограничен доменом Flow. Статус из MAIN-world сообщения носит информационный характер: сама веб-страница может его подделать. Телеметрия и загрузка исполняемого кода с сервера в проверенных исходниках не обнаружены.

Визуальная подпись версии в popup и диагностический ответ content-script пока содержат старое значение 0.1.0. Фактическая версия manifest — 0.1.1. Косметическое исправление этих файлов потребует новой версии расширения и новой подписи Mozilla; в этом выпуске они сохранены.

Автоматизация зависит от интерфейса браузеров и доступности UI Automation. Корпоративные политики, смена профиля, вмешательство пользователя во время установки и обновления браузеров могут потребовать отдельной проверки. Windows EXE не имеет подписи издателя. Аудит кода не означает разрешения Google на обход региональной проверки.
