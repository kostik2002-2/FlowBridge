# Установщик 0.1.3: запуск браузера

Установка не требует заранее открытого браузера или вкладки Flow.

- Закрытый браузер запускается сразу с адресом менеджера расширений.
- Выбирается настоящее окно с адресной строкой, а не временное окно запуска.
- В открытом браузере создаётся служебная вкладка. Перед вводом адреса проверяется её появление.
- Выбранное окно сохраняется на всё время установки.
- Введённый адрес проверяется до перехода. В Firefox используется запись значения адресной строки; для Opera учитывается задержка обновления.
- После установки используется та же служебная вкладка для запуска страницы подготовки расширения. Успех подтверждается переходом на домен Flow.
- В список выбора попадают только браузеры, для которых найден существующий исполняемый файл.
- Повторная установка актуальной версии сообщает «Расширение уже установлено».

## Локальная проверка на Windows

Проверялись реальные установленные браузеры с обычными профилями:

| Сценарий | Результат |
| --- | --- |
| Firefox закрыт, FlowBridge удалён | Подписанный XPI установлен; новая вкладка Flow открыта |
| Firefox открыт без Flow, FlowBridge удалён | Расширение установлено; Flow открыт; посторонние вкладки сохранены |
| Повторная установка в Firefox | Сообщение о существующей установке; список вкладок и границы окна сохранены |
| Chrome, Comet, Edge, Opera, Яндекс закрыты, FlowBridge удалён | Расширение установлено; открытие Flow подтверждено |

В проверке Firefox границы окна и состояние максимизации сравнивались до и после установки и повторного запуска. Координаты измерялись в одном режиме DPI.

14 JavaScript-тестов проверяют код расширения, включая сохранение посторонних вкладок и очистку cookies только точного домена Flow. Генерация не запускалась.

Подписанное Mozilla расширение остаётся версии 0.1.1 и не изменено. Эти проверки не гарантируют работу в каждом профиле, при корпоративных ограничениях или после изменения интерфейса браузеров.
